## 摘要
在本工作中，我们提出一个框架，将多智能体强化学习（MARL）与基于模型的控制相结合，以在多智能体协作任务中实现安全、动态可行的动作。多智能体强化学习的优势在于，能够从长规划时域中的离散不可微奖励中学习多智能体团队的协作策略。模型预测控制具有鲁棒性，并为短时域提供快速重规划框架下的安全、动态可行的动作。我们提出一种扩展了用于MARL的演员-评论家模型预测控制的算法，我们称之为多智能体演员-评论家模型预测控制（MA-AC-MPC）。我们通过将其应用于多智能体追逃场景来展示该算法的能力。具体而言，我们比较了使用MA-AC-MPC模型和多层感知机模型（MA-AC-MLP）的逃避者团队策略。追捕者团队采用增强比例导引，因为它被认为是一种先进的对抗控制律。我们还提供了一个异构环境的示例，其中一架无人机和一个全向轮式漫游车协作，在硬件上实现可重复的成功着陆，MA-AC-MPC的成功率达到100%，而MA-AC-MLP为60%。我们在硬件上证明了所提出的MA-AC-MPC算法在两种环境下的鲁棒性。

## Abstract
In this work, we propose a framework that combines multi-agent reinforcement learning (MARL) with model-based control to achieve safe, dynamically feasible actions in cooperative multi-agent tasks. Multi-agent reinforcement learning provides the advantage of learning cooperative policies for multi-agent teams from discrete non-differentiable rewards in a long planning horizon. Model-predictive control is robust and offers safe, dynamically feasible actions in a fast replanning framework for short horizons. We propose an algorithm that extends actor-critic model predictive control for MARL which we refer to as multi-agent actor-critic model predictive control (MA-AC-MPC). We demonstrate the capabilities of this algorithm by applying it to a multi-agent pursuit-evasion scenario. Specifically, we compare the evader team's strategy using the MA-AC-MPC model and a multi-layer perceptron model (MA-AC-MLP). The pursuer team uses augmented proportional navigation as it is accepted as an advanced adversarial control law. We also provide an example with a heterogeneous environment where a drone and omni-wheeled rover cooperate to achieve repeatable and successful landing with 100% success rate in hardware for MA-AC-MPC compared to 60% for MA-AC-MLP. We demonstrate the robustness of the proposed MA-AC-MPC algorithm in hardware for both environments.

- **核心问题**：在多智能体协作任务（如追逃对抗、异构平台协同）中，如何既能学习到长周期合作的策略，又能确保每个智能体输出**安全、动态可行**的动作。
- **研究背景**：
  - **MARL** 能从稀疏、非可微的团队奖励中学习协作策略，但缺乏对物理约束、安全性和分布外鲁棒性的保证。
  - **MPC** 能利用已知动力学模型提供安全、动态可行的控制，但其目标函数需人工设计且要求可微，难以应对复杂的多智能体合作问题。
- **整体含义**：提出将 **MARL 与 MPC 深度融合**，用学习获得高层合作意图，用模型优化保证底层动作的可行性，从而在安全关键的多智能体应用中实现可靠协作。

### 2. 论文提出的方法论
- **方法名称**：多智能体演员‑评论家模型预测控制（MA‑AC‑MPC）。
- **核心思想**：将单智能体 **AC‑MPC** 扩展至多智能体系统。
  - **演员结构**：分两层，上层为**成本网络**（神经网络），输入局部观测，输出 MPC 所需的参数（阶段参考、终端参考、权重矩阵）；下层为**可微 MPC 求解器**，根据成本网络给出的参数求解最优控制序列，并将首个动作作用于环境。
  - **评论家**：在训练时接入全局状态，实现集中式训练；执行时各智能体仅依赖局部观测，实现分散式执行。
- **关键技术细节**：
  - 采用 **MAPPO** 训练演员‑评论家网络，支持参数共享（同构智能体）。
  - 使用 **死亡掩码** 处理智能体中途失活的情况。
  - MPC 问题采用线性最小二乘形式，通过学习 \(y_{k,ref}, y_{N,ref}, W, W_N\) 编码合作任务。
  - 利用 **leap‑c**（基于 acados）作为可微 MPC 求解器，支持一般非线性不等式约束，且比 mpc.pytorch 更快。
  - MPC 预测时域 \(N=2\)，控制频率 50 Hz。

### 6. 论文的主要结论与发现
- **训练效率**：MA‑AC‑MPC 仅需 200 万步即达到高胜率，而更大 MLP 网络需近 400 万步，表明**模型信息能显著减少策略学习所需样本**。
- **鲁棒性**：在未经历过的质量变化下，MA‑AC‑MPC 的逃避者胜率**全面优于** MA‑AC‑MLP（热力图无蓝色区域）。
- **硬件迁移**：在着陆任务中，MA‑AC‑MPC 取得 **100% 成功率**，而 MLP 仅 60%，且误差更小、轨迹更一致，**验证了算法在真实系统中的高可靠性和可重复性**。

### 7. 优点
- **理论创新**：首次将 AC‑MPC 框架完整扩展至多智能体协作场景。
- **工程实现**：采用基于 acados 的更快速的 leap‑c，支持非线性约束，并开放了实验代码。
- **验证充分**：在两种截然不同的任务上（对抗与协作）进行了仿真和硬件验证，且进行了系统性鲁棒性测试。
- **训练课程**：通过逐步增加难度的课程设计稳定了高风险任务的训练过程。

### 8. 不足与局限
- **计算开销**：MPC 求解依赖 CPU，训练时间比纯神经网络长近一个数量级，可能限制大规模训练或需要实时 GPU 加速的场景。
- **MPC 时域**：仅验证了 \(N=2\) 的短时域，更长时域未带来增益，原因未深入分析。
- **环境规模**：实验最多 2 追 2 逃、2 异构智能体，未在更大规模集群上测试。
- **依赖精确模型**：MPC 需要较准确的环境动力学模型（尽管鲁棒性测试显示其可容忍一定模型失配），若真实模型未知或高度非线性，效果可能打折扣。

- **硬件试验次数**：着陆硬件试验仅 5 次，虽结果显著，但统计证据可更强。
