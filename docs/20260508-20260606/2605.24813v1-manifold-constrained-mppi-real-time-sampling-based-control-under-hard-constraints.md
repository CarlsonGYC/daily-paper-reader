## 摘要
基于采样的模型预测控制方法，如模型预测路径积分（MPPI），在复杂机器人系统中提供了无需求导的优化和鲁棒性。然而，标准MPPI依赖于基于成本的软惩罚，无法保证硬约束满足，严重限制了其在闭链操控等高约束任务中的应用。为此，我们提出流形约束MPPI（MC-MPPI），这是一种实时的基于采样的控制框架，在保持MPPI计算优势的同时强制执行基于流形的等式约束。其关键思想是将约束最优控制问题解耦为潜空间规划与执行级校正。在规划阶段，变分自编码器（VAE）学习约束流形的低维潜表示，使MPPI能够高效生成接近可行的候选轨迹，而无需逐样本修改。由于该参考轨迹能够实现等式约束的精确线性化，执行级二次规划（QP）控制器通过单次求解即可消除残余的流形失配，而无需迭代投影。在14自由度闭链双臂系统上的仿真和实际实验表明，MC-MPPI以100 Hz稳定运行，在动态环境中可靠导航的同时有效保持硬等式约束，并在跟踪精度上显著优于基线方法。补充视频与实现细节见https://rcilab.github.io/mcmppi。

## Abstract
Sampling-based model predictive control methods, such as Model Predictive Path Integral (MPPI), offer derivative-free optimization and robustness in complex robotic systems. However, standard MPPI relies on cost-based soft penalties that cannot guarantee hard-constraint satisfaction, severely limiting its applicability to highly constrained tasks such as closed-chain manipulation. To address this, we propose Manifold-Constrained MPPI (MC-MPPI), a real-time sampling-based control framework that enforces manifold-based equality constraints while preserving the computational advantages of MPPI. The key idea is to decouple the constrained optimal control problem into latent-space planning and execution-level correction. At the planning stage, a Variational Autoencoder (VAE) learns a low-dimensional latent representation of the constraint manifold, enabling MPPI to efficiently generate near-feasible candidate trajectories without per-sample modification. Since this reference enables accurate linearization of the equality constraints, an execution-level Quadratic Programming (QP) controller resolves the residual manifold mismatch in a single solve rather than through iterative projection. Experiments on a 14-DoF closed-chain dual-arm system in both simulation and real-world settings demonstrate that MC-MPPI operates stably at 100 Hz, reliably navigates dynamic environments while effectively maintaining hard equality constraints, and significantly outperforms baseline methods in tracking accuracy. Supplementary videos and implementation details are available at https://rcilab.github.io/mcmppi.

*   **核心问题**：基于采样的模型预测控制（如 MPPI）虽然无需求导、对局部极小值鲁棒，但其依赖代价函数中的软惩罚来处理约束，无法**保证硬约束（尤其是流形上的等式约束）被严格满足**。这导致 MPPI 在闭链双臂操作等**高约束任务**中极易因约束违反导致任务失败。
*   **研究背景**：标准 MPPI 的变体（如基于 CBF 的安全滤波、投影法、SVGD 等）主要处理不等式约束，难以处理具有零勒贝格测度的非线性等式约束流形。因此，亟需一种能够在采样框架下可靠执行硬等式约束的实时控制方法。

## 论文提出的方法论
方法核心是将约束最优控制问题解耦为 **“规划（慢频）”**和 **“执行（快频）”** 两个阶段。

*   **阶段一：潜空间规划（基于 VAE 的 MPPI）**
    *   **流形学习**：使用**变分自编码器（VAE）** 学习约束流形 `M = {q | h(q)=0}` 的低维潜表示。预训练的解码器 `ψθ` 可将低维潜变量 `z` 映射到近可行的关节构型 `q`。
    *   **潜空间控制**：在 `m` 维潜空间定义随机动力学 `zt+1 = zt + ût Δt`，其中 ût 为带噪声的潜空间速度。MPPI 直接在潜空间采样 `K` 条控制序列，并通过解码器得到近可行的候选轨迹。
    *   **高效采样策略**：采用**单实例采样**（整个预测时域使用同一个随机增量 `δu(k)`），使得潜轨迹平滑，避免解码器放大高频噪声导致关节抖动。
    *   **最优解生成**：在操作空间评估每条轨迹的代价，以重要性权重加权平均得到最优潜控制序列，并解码出近可行的参考构型 `q̂*`。

*   **阶段二：执行级修正（单步 QP 控制器）**
    *   **消除流形失配**：由于 VAE 解码器存在逼近误差，`q̂*` 并不严格在流形 `M` 上。利用 `q̂*` 提供的高精度线性化点，在**单个 QP 步**内求解以下优化以得到严格满足约束的构型 `q*`：
        ```text
        min sum( ||q̇ - q̇ref||^2 + w_task ||J_task q̇ - ẋ*_task||^2 )
        s.t. q = qc + q̇ Δt
             Jh q̇ = -α h(qc)      // 一阶泰勒展开的约束线性化
             q̇_min ≤ q̇ ≤ q̇_max
        ```
        其中参考速度 `q̇ref` 跟踪 `q̂*`。该 QP 通过单次求解即可驱除约束残差，无需迭代投影。
*   **整体架构**：上层规划器以 100 Hz 运行，下层执行器（QP + 位置控制器）以 500 Hz 运行，实现实时控制。

## 论文的主要结论与发现
1.  MC-MPPI 能在 **100 Hz** 下实现对硬等式约束的实时严格满足，平均约束违反量极低（<0.007）。
2.  解耦设计是关键：仅用潜空间规划（Latent MPPI）会因 VAE 残差而失败，单步 QP 修正必不可少。
3.  在 VAE 潜空间中采用**单实例采样（恒定增量）** 对探索效率和轨迹平滑至关重要，否则解码器会放大逐步噪声导致抖动和卡死。
4.  框架在真实双臂系统上能成功对移动障碍物做出反应，成功率 **95%**，验证了实用性。

## 优点
*   **创新性架构**：巧妙地将生成模型（VAE）的流形学习能力与 MPPI 的采样优化结合，并用单次 QP 弥合生成模型的精度缺陷，设计优雅。
*   **实时与硬约束兼得**：首次在采样型 MPC 中严格保证了等式硬约束，同时保持了 MPPI 的无导数并行计算优势。
*   **计算高效**：单步 QP 替代迭代投影，计算开销极小，切实保障了高频实时执行。
*   **实验扎实**：既有仿真消融，又有大量真实机器人试验，并公开了代码与视频，可复现性强。

## 不足与局限
*   **VAE 依赖性与泛化性**：需预先为特定约束场景训练 VAE，若约束变化（如被抓物体尺寸变化）则需重新训练。论文已指出未来将采用 CVAE 改善这点。
*   **不等式约束处理缺失**：障碍物避让、关节限位仍使用软惩罚，未集成到潜空间采样硬约束中，可能导致在极端动态环境下失败。
*   **比较对象有限**：未与处理硬约束的**传统梯度优化方法**（如 SQP、iLQR）在跟踪性能、约束满足度及计算效率上进行直接对比。
*   **QP 求解的鲁棒性**：虽然实验从未触发，但理论上 QP 有不可行风险，文中采用简单保持旧解的策略可能不够可靠。
